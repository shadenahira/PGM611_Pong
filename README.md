\# Créditos de recursos externos



Este proyecto utiliza algunos recursos gráficos y sonoros externos con fines

académicos. A continuación se reconocen los recursos utilizados y sus

respectivos autores o plataformas de procedencia.



\## Recursos gráficos



\### Breakout Pixel Art



Pack de recursos gráficos pixel art utilizado para personalizar elementos

visuales del juego.



\*\*Recursos utilizados:\*\*

\- `ball\_default`: sprite utilizado para la pelota.

\- `paddle`: sprite utilizado para las paletas de ambos jugadores.



\*\*Nombre del paquete descargado:\*\* `breakout\_pixel\_art`



Los recursos pertenecen a su respectivo creador y fueron utilizados únicamente

con fines académicos.



\### Modern City Backgrounds Pixel Art



Pack de fondos pixel art utilizado para personalizar el escenario del juego.



\- \*\*Recurso:\*\* Modern City Backgrounds Pixel Art

\- \*\*Autor/Publicador:\*\* Free Game Assets / CraftPix

\- \*\*Plataforma:\*\* itch.io

\- \*\*Uso en el proyecto:\*\* fondo pixel art de ciudad.



Fuente:

https://free-game-assets.itch.io/free-city-backgrounds-pixel-art
